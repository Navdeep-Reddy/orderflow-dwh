# AI usage disclosure

## Summary (honest version)
**The first complete version of this project — architecture, all source code, tests, generator, SQL, benchmark and docs —
was generated by Claude from the brief in a single assisted session** (see `PROMPT_HISTORY.md`). My prompts were short
("Pls build this project"), so the design decisions below are the assistant's proposals. My ownership of the work comes from
reviewing, running, questioning and (where needed) changing them — the sections marked ✍ must be filled in by me from what
I actually did before submission. Nothing in this file should claim review I have not done.

## Where AI accelerated the work
Scaffolding of every module; the SCD2 rebuild logic; the event-history design; the seeded generator with injected, labelled defects;
the 67 tests; reconciliation checks; benchmark; documentation drafts.

## Where I relied heavily on AI
* Design of the event-sourced order model and "rebuild affected customers" SCD2 strategy.
* SQL (upserts, window functions, point-in-time lookup).
* Test design (including tests that corrupt the DB to prove reconciliation works).
* Wording of README / data dictionary / design note.

## Things the AI itself verified (in its sandbox, reproducible by anyone)
* `make test` → 67 tests pass; sample, three other seeds and the late batch match the independent answer key.
* Fresh-copy flow `make test / run / validate / report` works (Python 3.12, SQLite 3.45).
* Benchmark on 151k rows; index optimisation measured (≈180×). A first version of that measurement was **wrong** (`COUNT(*)` let
  SQLite skip the subquery) and was fixed after the numbers looked implausible.
* Test failures found and fixed during the session were mistakes in test expectations, not pipeline bugs
  (reject-ratio gate tripping on tiny files, a `substr` offset, a miscounted customer total, a default-parameter mismatch in the generator).

## Not verified by the AI
Other Python versions (only 3.12 tried; code targets 3.10+), running under pytest (not installable in its sandbox),
other operating systems, hardware-dependent timings.
